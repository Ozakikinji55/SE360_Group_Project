# 老师的要求
## 以下部分是我理解的, 如果有不对的地方, 请指正
m是全局的样本
n是我们要讨论的样本, 注意, 后续提到“样本指的是这个”
k是你要选取的数量——例如, n=7, k=6, 就是从7个样本里面选取6个
j是我们要选取的比较库(挑战者池)的长度
s是覆盖一个挑战者最少的元素数量

例如:

m=5, n=4, k=3, j=2, s=2;
1-从m中挑选n个, 此处暂时略过
我们假定选择的4个是A,B,C,D
2-当你从4个选择3个的时候, 你可以得到: ABC, ABD, ACD, BCD
3-同时, 我们就要考虑挑战者池子了, 这里会用来比较——4选2, AB,AC,AD,BC,BD,CD
4-由于s=2, 所以当一个组合(ABC, ABD, ACD, BCD)任何一个元素, 只有完整的找到4选2中的元素之后, 比较池才能判断比完了
例如, ABC, 此处涵盖AB, AC, BC, 所以在下一次计算的时候, 比较池只剩下AD,BD,CD, 同时将ABC加入运行结果
5-以此类推, 直到比较池变空


m=5, n=4, k=3, j=2, s=1;
此时和上面不一样的是——只要涵盖二元组合的一个元素, 就算涵盖.
例如:
ABC, 此时AB符合(含有A), AC符合(含有A), 
对于BD而言, 因为有B, 哪怕没有D, 也算通过
此时, 比较池空了
所以结果=ABC
